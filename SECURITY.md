# Security Policy

## Supported Versions

Version 1.0.x is the first release line.

| Version | Status |
|---------|--------|
| 1.0.x   | Supported |
| < 1.0   | Not released; unsupported |

## Reporting a Vulnerability

If you discover a security vulnerability in Boutquin.Mediator, report it responsibly.

Do not open a public issue for security vulnerabilities.

Please use GitHub Security Advisories to report vulnerabilities privately:
https://github.com/boutquin/Boutquin.Mediator/security/advisories/new

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- Acknowledgment: within 48 hours
- Initial assessment: within 7 days
- Fix or mitigation: target within 30 days, depending on severity

### Scope

This policy covers the `Boutquin.Mediator.Abstractions`, `Boutquin.Mediator`, `Boutquin.Mediator.Authorization`, `Boutquin.Mediator.Caching`, `Boutquin.Mediator.Reliability`, `Boutquin.Abstractions`, and `Boutquin.Reliability` NuGet packages and their source code. Third-party dependencies (for example the .NET runtime, Polly, and other NuGet dependencies) should be reported to their maintainers.
